# Demo — RRR Motos (Testimonials)

Setup rápido para rodar localmente o componente de depoimentos.

1. Instale dependências:

```bash
npm install
```

2. Rode em modo desenvolvimento:

```bash
npm run dev
```

3. Abra o endereço mostrado pelo Vite (geralmente `http://localhost:5173`).

Observações:
- O demo usa `lucide-react` para ícones. Já está listado em `package.json`.
- As classes CSS no componente assumem Tailwind; se não usar Tailwind, crie `src/styles.css` com estilos alternativos ou instale e configure Tailwind.
